# Crypto Portfolio Tracker

Real-time cryptocurrency portfolio tracker with live WebSocket prices, alerts, and P&L analytics.

## Features
- 📊 Real-time prices via CoinGecko (30s refresh)
- 💼 Portfolio tracking with P&L calculation
- 🔔 Price alerts (above/below target)
- 📈 7-day sparkline charts
- 🔄 WebSocket live price stream
- 📱 Responsive dashboard

## Tech Stack
- Node.js, Express, WebSocket, MongoDB, CoinGecko API, node-cron

## Getting Started
```bash
npm install && cp .env.example .env && npm run dev
```
